# u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163

The Funniest Excuse for Skipping a Meeting — one razor-sharp line, 200 characters or fewer, that gets you out of a pointless meeting.

`main.py` prints the entry line to stdout:

> Sorry, I can't make it — I'm stuck in a meeting about why we're always in meetings instead of doing any actual work.

Run it with `python3 main.py`. The entry text is in `entry.txt`.
